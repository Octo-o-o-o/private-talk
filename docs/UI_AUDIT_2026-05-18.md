# Private Talk UI 一致性审计 · 2026-05-18

本审计在保留现有"iOS 26 玻璃感 / 深色基底"风格的前提下，逐一检查 Welcome / List / Chat / Settings / Pin 等界面，以及 Mobile / Tablet / Desktop 各响应式断点。仅聚焦对齐、间距、字号、字重、配色一致性等细节问题，不改动视觉设计方向。

---

## 一、问题清单（精炼版，已剔除误判项）

### A. 配色 / 主题 — P0

#### A1. light 主题下用户气泡里的「编辑 / 重试 / 删除」按钮几乎不可见 ⛔
- **位置**：`.pt-message__action` (`src/index.css` 1331–1366)
- **现象**：dark 主题下 `.pt-message__bubble--user` 背景写死 `white`，所以 action 按钮用 `color: rgba(15,23,42,0.78); background: rgba(15,23,42,0.08);` 能正常显示。但 light 主题里 `.pt-message__bubble--user` 被覆写成 `background: var(--accent) = #171717; color: #fff;`，而 action 按钮颜色 / 背景没相应变化，**几乎完全不可见**。
- **解决方案**：让用户气泡走主题变量 `--user-bubble-bg` / `--user-bubble-fg`，action 按钮颜色 / 背景从这两个变量派生（`color-mix` 出半透明前景与微弱底色）。

#### A2. 用户气泡背景与 action 按钮颜色全部硬编码
- **位置**：`.pt-message__bubble--user { background: white; color: var(--text-dark); }` + `.pt-message__action`
- **现象**：与 A1 同根。颜色直接写在 base layer，没走主题变量。
- **解决方案**：新增 `--user-bubble-bg` / `--user-bubble-fg` / `--user-action-bg` / `--user-action-fg` / `--user-action-bg-hover` 五个变量，dark 与 light 各定义一份；删掉 `:root[data-theme="light"] .pt-message__bubble--user` 的覆写。

---

### B. 控件尺寸一致性 — P0 / P1

#### B1. 侧边栏底部「新建聊天」「设置」高度不一致 ⛔
- **位置**：`.pt-inline-button` `min-height: 46px` vs `.pt-nav-button` `min-height: 48px`
- **现象**：这两个按钮在 sidebar 底部上下相邻，高度差 2px 肉眼可见。
- **解决方案**：统一为 `min-height: 44px`（与 input / select 一致），借助 `--control-h-md` 这样的语义 token 收敛。

#### B2. compose-field 左右 padding 不对称
- **位置**：`.pt-compose__field { padding: 6px 6px 6px 18px; }`
- **现象**：左 padding 18、右 padding 6。左侧只有一个工具按钮，右侧三个工具按钮 + 一个发送按钮，看起来"重头轻尾"，第一个工具按钮离 textarea 也比右侧按钮组之间更远。
- **解决方案**：改为 `padding: 6px;`，让 4 个工具/发送按钮和 textarea 之间的视觉节奏一致。

#### B3. 控件高度散落（按钮 / chip / 输入框）
- **现象**：项目内同时存在 `min-height: 28 / 32 / 36 / 38 / 40 / 42 / 44 / 46 / 48` 至少 9 档高度。
- **解决方案**：引入 4 档语义 token：`--control-h-xs: 28px; --control-h-sm: 32px; --control-h-md: 40px; --control-h-lg: 44px;`，把现有控件按语义归类。原则上：tag / pill = xs，row-icon = sm，icon-button / compose-tool / send / select = md，inline / nav / btn / input = lg。

---

### C. 字号 / 字重 / 字距 收敛 — P1

#### C1. 大量带小数的字号（10.5 / 11.5 / 12.5 / 13.5 / 14.5 / 15.5 / 10.75）
- **位置**：全局 CSS，>30 处
- **现象**：跨平台亚像素渲染抖动，且让设计 token 难以维护。
- **解决方案**：取一套 7 档无小数字号 `10 / 11 / 12 / 13 / 14 / 15 / 16`，把 10.5 → 11，11.5 → 11 或 12（按用途），12.5 → 12，13.5 → 13，14.5 → 14（除非作 H4 提升到 15），15.5 → 15。22px 等大字号保留不动。

#### C2. 字重梯度散落（550 / 560 / 580 / 600 / 620 / 650 / 680 / 700）
- **现象**：相近字重 8 档，没有清晰的层次感。
- **解决方案**：收敛到 4 档：`400 / 500 / 600 / 700`。规则：body 400，row title / inline button 500，section / panel / strong 600，display title 700。

#### C3. 多套 "eyebrow / section-title" 样式
- **位置**：`.pt-sidebar__eyebrow` / `.pt-sidebar__section-title` / `.pt-settings-panel__eyebrow` / `.pt-settings-section__title` / `.pt-assistant-inline__label`
- **现象**：5 处大写小标签，font-size 在 10.5 / 11 之间漂移，font-weight 在 650 / 700 之间漂移。
- **解决方案**：统一字号 11、字重 600、letter-spacing 0.08em、color text-tertiary，命名 `--type-eyebrow`，所有 5 处共用一个 mixin / 选择器组。

#### C4. pane-header subtitle 对比度偏低
- **位置**：`.pt-pane-header__subtitle { color: var(--text-tertiary); font-size: 10.5px; }`
- **现象**：dark mode 下 `rgba(255,255,255,0.38)` × 10.5px，WCAG AA 边缘水平（约 4–5 : 1）。
- **解决方案**：字号收敛到 12，颜色改为 `--text-secondary`（透明度 0.66），同时保持单行 ellipsis。

---

### D. 形状 / 圆角 token — P1 / P2

#### D1. 设置左侧菜单按钮 active 状态显示为矩形
- **位置**：`.pt-settings-menu-button` 自身 `border-radius: 0`，`.pt-settings-menu-card` 用 `overflow: hidden + border-radius: 24px` 来兜外圆角。但中间项 active 时背景填满整行，呈现矩形高亮。
- **解决方案**：给 `.pt-settings-menu-button` 在外卡片内部加内 `margin: 4px` + 自身 `border-radius: 16px`，让选中项是独立圆角块；同时去掉相邻边框分隔线，改用 4px 间距视觉切割。

#### D2. message-action pill 形状与气泡风格脱节
- **位置**：`.pt-message__action { border-radius: 999px; }`
- **现象**：气泡是 20/6 的非对称圆角，action 是完全的胶囊，挂在气泡底部看起来风格不连续。
- **解决方案**：改为 `border-radius: 10px`，与气泡的 6px 小圆角呼应。

#### D3. 圆角硬编码值散落
- **现象**：`14 / 18 / 24 / 26 / 34` 多个圆角不在 token 体系 (`--radius-shell 32 / panel 28 / card 20 / field 16 / pill 999`) 内。
- **解决方案**：把 14 / 18 → 16（field），24 → 20（card），26 → 28（panel）或 32（shell，pin-card），34 → 32（shell）。

---

### E. 主题颜色补完 — P1

#### E1. user 气泡相关变量缺失
- 见 A1 / A2。新增的变量：`--user-bubble-bg`、`--user-bubble-fg`、`--user-action-bg`、`--user-action-fg`、`--user-action-bg-hover`。

#### E2. light 主题 user 气泡阴影未单独定义
- **现象**：`.pt-message__bubble { box-shadow: 0 14px 32px -26px rgba(0,0,0,0.9); }` — light 主题下 0.9 黑色阴影在浅色背景上太重。
- **解决方案**：引入 `--bubble-shadow`，light 用 `rgba(82,63,32,0.18)`，dark 沿用现有值。

---

### F. 响应式 — P2

#### F1. tablet (768–959) 断点下 chat header 标题易被截断
- **位置**：`.pt-provider-controls .pt-select { min-width: 132px; max-width: 176px; }` × 2 + gap 10，占去 274–362px
- **现象**：tablet panel 总宽 ~720px，剩给 title 的位置只有 ~350px，中文长会话名容易省略号。
- **解决方案**：tablet 断点下把 provider select 的 max-width 收紧到 160，model select 收紧到 150；同时 select font-size 不缩小，靠 padding 控制视觉。

---

### G. 抛光（可做可不做）— P3

#### G1. chat-scroll 底部与 compose 顶部无渐变过渡
- **现象**：长消息直接被 compose 切平，缺一个 mask / scrim 过渡。
- **解决方案**：在 `.pt-chat__scroll` 底部 18px 加 `mask-image: linear-gradient(to bottom, black calc(100% - 24px), transparent)`。

#### G2. ChatInput placeholder 在图片模式下文案过长，mobile 易截断
- **现象**："描述你想生成的图片，也可以继续写 --ratio / --quality / --count / --bg" 约 32 字。
- **解决方案**：mobile 视口下截断为 "描述你想生成的图片"，详细 flag 提示放到 pane 内 notice。

#### G3. 用户气泡 max-width 用 `min(78%, 68ch)` 中文场景下 68ch 失效
- **解决方案**：改为 `max-width: 78%`，删除无意义的 68ch。
