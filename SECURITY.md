# Security Policy

## Supported Versions

Security fixes are handled on the latest code on the default branch and the latest published release, if one exists.

## Reporting a Vulnerability

Please do not open public GitHub issues for security-sensitive reports.

Preferred reporting path:

- Use GitHub private vulnerability reporting for this repository if it is enabled.

Fallback path:

- Contact the maintainer through [clawbutler.cc](https://clawbutler.cc) and request a private reporting channel.

When reporting, include:

- affected version or commit
- operating system
- reproduction steps
- impact assessment
- logs or screenshots if they do not expose secrets

I will handle reports on a best-effort basis and coordinate a fix before public disclosure when possible.
